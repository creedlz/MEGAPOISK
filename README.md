# MEGAPOISK

This is my project for searching Word, Excel, and TXT files by keyword, number, or phrase.
I’m not sure if this is worth mentioning, but in case anyone’s interested: the code runs on Python 3.14 and uses built-in libraries, so I don’t think you’ll have any trouble setting it up.

The program works like this: you need to select the shortest path to the files you want to search, but you can also select Drive C:—it will find everything there, though the program will have to preload a bit, so it will take longer. Then you need to type a digit, number, word, phrase, letter, etc., and click “Find.” It will then display all files containing the search term, indicating in which file it appears—if in a Word document, which paragraph; if in an Excel sheet, which row and column. You can also click on a file and then click the “Open” button to open it. There’s also a search history (I couldn’t quite get the history feature to work properly—it didn’t turn out right. I’m waiting for advice). You can also set up favorite folders to open them with a double-click, and search by filename—but it’s about 1.5 to 2 times faster than Windows Explorer.

I’d love for someone to suggest how to improve this. I’m always open to advice. Enjoy using it!

Это мой проект для поиска в ворд/ексель/тхт по ключевому слову/числу/предложению.
Не знаю, стоит ли об этом упоминать, но если кому-то интересно: код работает на Python 3.14 и использует встроенные библиотеки, так что, думаю, с его настройкой не должно возникнуть сложностей.

Программа работает по такому принципу что нужно выбрать ближайший путь к тем файлах в которых вы хотите искать, но можно и выбрать диск С и оно найдёт только програма чутка залагает и это будет дольше. Потом нужно написать цифру/число/слово/предложение/букву и т.д. ит нажать найти после чего выдаст все файли с упоиманием в каком файле, если ворд то на каком обзаце, а если в ексель то на каком числе и букве. И можно нажать на файл и на кнопку открыть чтоб открыть файл. Также есть история поисков (я не смог довести историю до ума. ну не получилось. жду совета) Также есть возможно сделать избранные папки чтоб по двойному нажатию их открывать, а и поиск по имени файл, но быстрее чем проовдник виндовс примерно в 1.5х-2х.

Мне хотелось бы чтоб кто-то подсказал как лучше сделать. Я всегда рад совету. Приятного пользования!
